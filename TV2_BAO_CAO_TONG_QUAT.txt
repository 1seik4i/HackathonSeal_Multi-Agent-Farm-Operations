--------------------------------------------------------------------------------
1. QUY TRINH XU LY DU LIEU CAM BIEN CHUAN (DETERMINISTIC TIMESTAMP PIPELINE)
--------------------------------------------------------------------------------

Nhóm TV2 tuân thủ nghiêm ngặt quy trình 2 giai đoạn cho dữ liệu cảm biến:
TU DONG PHAN LOAI BOI PYTHON CODE TRUOC -> SAU DO MOI CHUYEN DU LIEU FRESH CHO LLM PHAN TICH

timestamp (Mốc thời gian cảm biến)
   ↓
Python Code (Kiểm tra chênh lệch thời gian với Cấu hình stale_after_seconds = 300s)
   ↓
   ├──> FRESH   (Nếu timestamp <= 300s, phân loại 100% bởi Python Code)
   ├──> STALE   (Nếu timestamp > 300s, phân loại 100% bởi Python Code)
   └──> MISSING (Nếu không có dữ liệu, phân loại 100% bởi Python Code)
   ↓
Dữ liệu FRESH (Được Python chứng thực)
   ↓
LLM Phân Tích (Gemini 3.5 Lite / GPT-OSS 120B suy luận nông học & đàm phán)

Lưu ý quan trọng: LLM KHONG tự ý quyết định nhãn FRESH, STALE hay MISSING. Các nhãn này được tính toán hoàn toàn bằng thuật toán mã nguồn Python dựa trên timestamp thực tế. LLM chỉ nhận các dữ liệu đã được chứng thực FRESH để thực hiện phân tích ngữ nghĩa nông nghiệp.

--------------------------------------------------------------------------------
2. TONG QUAN NHUNG THAY DOI & NANG CAP KY THUAT DA THUC HIEN
--------------------------------------------------------------------------------

1. Xoa Bo Hoan Toan Nguong Gan Cung (soil < 35, sun > 40000):
   - Thay thế các câu lệnh if-else tĩnh bằng Mô hình AI Suy luận Động (Pure Dynamic AI Reasoning).
   - Gemini 3.5 Flash-Lite LLM đọc mốc thời gian (Tháng/Mùa trong năm), nhiệt độ, độ ẩm không khí, bức xạ ánh sáng để tự tính toán Ngưỡng Độ Ẩm Động (dynamic_threshold) và ra quyết định tưới.

2. Cau Hinh 4 LLM Doc Lap Cho 4 Agent (4-LLM Architecture):
   - FieldIoTAgent (LLM 3): Nhận danh sách FRESH từ Python Code, thực hiện nhận xét kỹ thuật trường.
   - IrrigationPlanningAgent (LLM 1): Gemini 3.5 Flash-Lite tự chủ lập kế hoạch nông học dựa trên dữ liệu FRESH.
   - ResourceAgent (LLM 2): GPT-OSS 120B thẩm định mực nước, pH, công suất bơm và đàm phán.
   - FarmCoordinatorAgent (LLM 4): Gemini 3.5 tổng hợp báo cáo chỉ đạo điều hành cấp cao (ai_executive_summary).

3. Quan Ly API Keys Trong File Doc Lap (api_keys.env):
   - Tách riêng biệt file api_keys.env quản lý 4 API Key độc lập. File src/settings.py tự động nạp đồng thời .env và api_keys.env.

4. Tich Hop Du Lieu Nong Nghiep Tu TV1 (MongoDB Atlas Pipeline):
   - FieldIoTAgent đọc dữ liệu cảm biến thời gian thực của 6 thiết bị từ MongoDB Atlas via MongoTelemetryStore (với fallback SQLite tự động khi ngắt kết nối).

5. Expose REST APIs Cho Frontend Render (TV3 Integration):
   - Cung cấp API POST /api/coordinate trả về ai_executive_summary, agent_dialogue (cuộc hội thoại đối thoại đàm phán giữa các LLM Agents) và agent_trace (bảng xác minh 4 bước).

4. VAI TRO & CACH THUC HOAT DONG CU THE CUA TUNG AGENT
--------------------------------------------------------------------------------

4.1. FieldIoTAgent (Giám Sát & Phân Tích Cảm Biến AI):
- Quy trình:
  1. Python code kiểm tra timestamp -> Gắn nhãn FRESH / STALE / MISSING (Phân loại 100% bằng thuật toán Python).
  2. Dữ liệu FRESH được truyền sang GPT-OSS 120B #2 (GPT_OSS_2_API_KEY) để đưa ra nhận xét kỹ thuật trường.

4.2. IrrigationPlanningAgent (Chuyên Gia Nông Học AI):
- LLM Đảm Nhiệm: Google Gemini 3.5 Flash-Lite #1 (GEMINI_API_KEY).
- Quy trình:
  1. Nếu cảm biến đất bị STALE hoặc MISSING (đã được Python phân loại) -> Lập tức trả về NEEDS_FIELD_CHECK (Không để LLM ảo tưởng).
  2. Nếu dữ liệu FRESH -> Gemini LLM đọc mốc thời gian, nhiệt độ, độ ẩm không khí, bức xạ ánh sáng để tự tính toán Ngưỡng Độ Ẩm Động (dynamic_threshold) và ra quyết định tưới tiêu.

4.3. ResourceAgent (Kỹ Sư Quản Lý Hạ Tầng AI):
- LLM Đảm Nhiệm: OpenAI GPT-OSS 120B #1 (GPT_OSS_API_KEY).
- Vai trò:
  + Nhận thông điệp đề xuất từ Gemini Agent #1, thẩm định các điều kiện hạ tầng vật lý (Bể nước >= 25%, pH 5.5 - 7.5, Bơm 10 - 25 L/min).
  + Phát biểu câu đàm phán phản hồi lại Gemini Agent: ĐỒNG Ý (Approved) cấp nước hoặc TỪ CHỐI (Blocked) do vi phạm an toàn hạ tầng.

4.4. FarmCoordinatorAgent (Trưởng Ban Điều Phối AI):
- LLM Đảm Nhiệm: Google Gemini 3.5 #2 (GEMINI_2_API_KEY).
- Vai trò:
  + Thu thập toàn bộ cuộc đối thoại 3 bên (agent_dialogue) giữa Agent 1, Agent 2 và Agent 3.
  + Tổng hợp kết quả và sinh ra Báo cáo tóm tắt chỉ đạo điều hành cấp cao (ai_executive_summary) từ 2-3 câu gửi thẳng cho Quản lý trang trại trên Frontend.
